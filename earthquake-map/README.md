# 지진 지도 프로토타입

브레인스토밍용 데모입니다. MyStockApp(주식 뉴스 파이프라인)과는 무관한 독립 프로토타입이며,
어디에 정식으로 둘지는 아직 정해지지 않았습니다.

## 왜 HTML 한 장이 API를 직접 호출하지 않나

`apis.data.go.kr`는 브라우저 CORS 헤더를 내려주지 않는 경우가 많아, 정적 HTML에서
`fetch()`로 직접 호출하면 브라우저가 요청을 막습니다. 그래서 이 프로토타입은:

1. `fetch-quakes.mjs` (Node 스크립트)가 서버 사이드로 기상청 API를 호출하고,
2. 결과를 반영한 `map.html`(Leaflet 지도)을 생성합니다.

서비스키가 제3자 프록시로 새어나가지 않는다는 장점도 있습니다.

## 사용법

1. [공공데이터포털](https://www.data.go.kr)에서 "기상청_지진정보 조회서비스"를 신청해
   서비스키(Decoding 키)를 발급받습니다. (승인까지 시간이 걸릴 수 있습니다)
2. 실행:
   ```bash
   KMA_SERVICE_KEY=발급받은키 node earthquake-map/fetch-quakes.mjs 30
   ```
   (마지막 인자는 조회할 최근 일수, 기본 30일)
3. 생성된 `earthquake-map/map.html`을 브라우저로 엽니다.

## 알려진 한계 (프로토타입 단계)

- 이 API의 정확한 응답 필드명(위도/경도/규모 등)을 공식 문서에서 확인하지 못했습니다
  (이 개발 환경의 네트워크 정책상 data.go.kr 접근이 차단되어 있음). `fetch-quakes.mjs`
  상단의 `FIELD_CANDIDATES`에 후보 필드명을 넣어뒀고, 매칭에 실패한 항목은 콘솔에
  원본 데이터와 함께 경고를 출력하므로, 실제 키 이름을 확인해 그 배열을 고치면 됩니다.
- 이 서비스는 실시간 지진 알림보다는 발표된 지진통보문 조회에 가깝습니다. 실시간성이
  중요하면 기상청 API허브(apihub.kma.go.kr)의 다른 지진 API도 검토해볼 만합니다.
- 에러 처리, 캐싱, 자동 갱신 등은 없습니다 — 말 그대로 데모입니다.
